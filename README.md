# Rocha Bakery & Café

Proyecto académico en el que los estudiantes rediseñaron los procesos de gestión de Rocha Bakery & Café y los integraron en un sistema web.

El sistema permite controlar el inventario de ingredientes, gestionar recetas y producción por lotes, registrar pedidos y ventas, y consultar gastos y reportes contables. La reingeniería conectó estos procesos para dar seguimiento a la operación desde la compra de insumos hasta el registro de la venta.
